Recorded setup questions, one folder per language code (hi, or, te, kn, ta, en).
File names and the sentences to say: android/tools/onboarding_audio_script.md
Missing files are fine: the app then speaks the question with its own voice or the phone's.
pick_language.wav (in this folder): the spoken language menu on the first screen, each line in its own
language. Made by android/tools/tts/make_language_prompt.py; a native recording with the same name can replace it.
